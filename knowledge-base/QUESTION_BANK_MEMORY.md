# ED Question Bank Memory

Working rules agreed with user for this project:

- Build one single master workbook only: `ED coding master.xlsx`.
- Do not create multiple delivery files for ED bank batches.
- Use tag `ED coding` for the bank unless user explicitly asks for a different tag.
- Keep the `answer` column blank; rely on options, `correct_option`, and rationale.
- Target total bank size: about 250 to 270 questions, with quality preferred over quantity.
- Prefer batches of about 40 questions for iterative review and refinement.
- Maintain a balance of:
  - recall/guideline questions
  - scenario-based coding/application questions
  - code-selection questions
  - documentation trap questions
- Especially for injections and infusions, include realistic human stems with:
  - age/setting/context
  - drug names where helpful
  - start and stop times
  - access site details when relevant
  - same-drug vs new-drug logic
  - hydration interruption logic
  - separate-site logic when relevant
- Questions must feel human-made, educational, and exam-practical.
- Distractors should be close, logical, and related; avoid obviously wrong filler options.
- Rationales must be learner-facing and self-contained.
- Never mention source documents in learner-facing question text or rationales.
  - Do not say "the handbook says," "the AHIMA article says," "the notes say," or similar.
- Source PDFs are for internal creation support only and should stay ignored from Git.
- Current source set includes ED bedside procedures plus multiple injections/infusions references.
- Injections/infusions may include both theory and application, but must not skew too theoretical.
- Educational value matters: rationale should explain why the right answer is right and why the coding logic applies.
